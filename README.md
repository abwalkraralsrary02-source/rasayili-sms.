# تطبيق "رسائلي" (Rasayili) لنظام Android

تطبيق رسائل SMS خلوي أصلي ومفتوح المصدر 100% مبني بأحدث تقنيات أندرويد: **Kotlin** و **Jetpack Compose**، متوافق مع هواتف **Android 9.0 (API 28 - Pie)** وما بعده حتى **Android 15 (API 35)**.

---

## 🚀 كيفية تحويل هذا المشروع إلى ملف APK تلقائياً عبر GitHub:

لقد قمنا بتجهيز ملف **GitHub Actions** في المسار `.github/workflows/build-apk.yml`. بمجرد رفع هذا المجلد إلى حسابك في GitHub، سيقوم خادم GitHub ببناء ملف الـ APK لك مجاناً وتوفير رابط مباشر لتحميله دون الحاجة لتثبيت أي برامج على حاسوبك!

### الخطوات بالتفصيل:
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في [GitHub](https://github.com).
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى المستودع:
   ```bash
   git init
   git add .
   git commit -m "الإصدار الأول من تطبيق رسائلي"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. توجه إلى تبويب **Actions** في صفحة المستودع على GitHub.
4. ستجد مهمة البناء **Build Android APK** قيد التشغيل التلقائي.
5. بعد انتهاء البناء (يستغرق حوالي دقيقة إلى دقيقتين)، اضغط على اسم العملية وستجد في الأسفل قسم **Artifacts** يحتوي على ملف:
   **`Rasayili-SMS-Debug-APK`**.
6. حمله وثبته مباشرة على هاتفك الأندرويد!

---

## 📱 ميزات التطبيق:
- **واجهة عربية كاملة RTL**: تصميم حديث بـ Material 3.
- **بدون إنترنت إطلاقاً (100% Offline)**: لا يوجد تصريح `INTERNET` نهائياً؛ رسائلك مشفرة محلياً على جهازك ولا يمكن تسريبها.
- **إرسال حقيقي واستقبال SMS عبر الشريحة**: دعم الشرائح المتعددة (Dual SIM) وتجزئة الرسائل الطويلة بدقة (70 حرفاً للترميز العربي UCS-2).
- **إشعارات الرد السريع**: إشعار رأسي (Heads-Up) مع إمكانية الرد الفوري من شريط الإشعارات.
- **تطبيق SMS الافتراضي**: امتثال كامل لمعايير Android 9 وحتى Android 15 عبر `RoleManager` و `Telephony Provider`.
- **أداء فائق للهواتف الاقتصادية (2GB RAM)**: استهلاك ذاكرة منخفض وسرعة استجابة فائقة.

## 🛠️ البناء محلياً عبر Android Studio أو سطر الأوامر:
```bash
# بناء نسخة التجربة والتصحيح
./gradlew assembleDebug

# تثبيت التطبيق مباشرة على هاتفك المتصل عبر USB
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
